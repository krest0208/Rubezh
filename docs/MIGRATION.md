# Перенос «Рубежа» на C#

## Происхождение

База: `71e0b11c4b0329de468649b31a664d57f733cb31`. В ней 14 из 19 частей.
SHA-256 имеющихся 8 363 775 байт:
`16237f7c2c68139e9471aed398a19c6935fc7f094b58a38769c5097e4008d724`.
Оригинальная ожидаемая сумма v12 не подменена.

`tools/extract_native_data.mjs` соединяет имеющиеся байты и извлекает завершённые
литералы данных, а не запускает обрезанный игровой код. Кампания хранится в gzip JSON;
декомпрессия выполняется средствами .NET при старте. Извлечение проверяет 1000 миссий
для каждого из шести языков. Происхождение описано в `Data/provenance.json`.

## Архитектура

- `Content`: типизированные определения, модели и записи кампании.
- `Battle`: фиксированный шаг, состояния подготовки/волны/победы/поражения,
  размещение, экономика, урон, броня и артподдержка. Только System.Numerics.
- `Profile` / `ProfileStore`: метапрогресс, исследования, владение косметикой,
  транзакционное сохранение. Godot и JSON браузера не требуются.
- `App`: навигация и композиция экранов; загрузка контента.
- `BattleView` / `BattleBoard`: управление и отображение без расчёта урона.
- `ArmoryView`: покупка и выбор модели. В боевое ядро геометрия не передаётся.

Симуляция использует фиксированные 60 шагов/с. ×2 меняет число шагов, а не
характеристики. Противник движется по маршруту, цели выбираются по прогрессу;
стрелки предпочитают быстрые цели. Погибший враг приносит награду только один раз.
Танки могут повреждать позиции, поэтому ремонт и укрепление имеют игровое действие.

## Визуальный подход

Сохранён вид сверху в 2D. У каждого типа три авторские SVG-модели. Меняются опора,
корпус, стволы, размеры, ходовая часть и навесное оборудование. Примеры:

| Тип | Базовый | Альтернатива 1 | Альтернатива 2 |
|---|---|---|---|
| Пулемёт | Расчёт на треноге | Бетонный ДОТ | Гусеничная спарка |
| Пушка | Колёсный лафет | САУ с рубкой | Двухствольный каземат |
| Сапёры | Минный пост | Тягач с отвалом | Радиостанция с выносными модулями |
| Транспорт | Тент | Ящики в открытом кузове | Цистерна |
| Разведчик | Пехотинец | Мотоцикл с коляской | Колёсный бронедозор |

Исходный генератор геометрии находится в `tools/build_models.mjs`; модели можно
редактировать в любом SVG-редакторе, затем перенести изменения в генератор для
воспроизводимости. Все формы оригинальные; сторонние пакеты графики не использованы.
Некоторые варианты намеренно стилизованы и не претендуют на историческую точность.

## Реализовано заново, а не восстановлено

Формирование волн, уровни улучшений, контратаки брони, пороги наград, маршрутизация,
экраны и сохранения. Наличие 1000 записей не означает ручную проверку 1000 уровней.
Автотесты проверяют геометрию всех маршрутов и прохождение первой операции.
Данные `trait`, погода, сюжетные письма сохранены; из них в интерфейсе отображаются
история, цель, подсказка и исход операции. Погодная симуляция и отдельный журнал
писем пока отсутствуют. Интерфейс RU; локализации текстов миссий сохранены полностью.
