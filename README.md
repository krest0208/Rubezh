# Рубеж

2D tower defense по мотивам Второй мировой войны: 1000 миссий, выживание, прокачка укреплений, динамическая сложность, шесть языков и косметический магазин.

## Структура

- `web/index.html` — основная игра, запускается в современном браузере.
- `tools/build_apk.py` — офлайн-сборщик лёгкого WebView APK. Приватный ключ подписи в репозиторий **не входит**.
- `android-admob/` — Android Studio проект с Google Mobile Ads SDK и rewarded-рекламой. По умолчанию используются только официальные тестовые ID Google.

## Магазин скинов

В главном меню есть отдельная кнопка «Магазин». Внутри сначала выбирается башня или враг, затем конкретный объект, после чего снизу листаются его скины. Нажатие на скин только открывает предпросмотр; покупка и экипировка выполняются отдельной кнопкой.

## Rewarded Ads

Проект `android-admob` использует тестовый rewarded ad unit Google. Перед публикацией замените `ADMOB_APP_ID` и `ADMOB_REWARDED_ID` в `android-admob/app/build.gradle` на значения из вашего AdMob аккаунта. Не используйте боевые рекламные ID при тестировании.

Для пользователей в регионах, где требуется согласие, проект включает Google UMP SDK и запрашивает актуальное состояние согласия до загрузки рекламы.

## Важно о подписи

Никогда не публикуйте приватный release-keystore или PEM-ключ в GitHub. Для обновления уже установленного APK подписывайте новые релизы тем же приватным ключом, который использовался раньше.
